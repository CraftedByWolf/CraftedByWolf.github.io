How to actually learn it

Rules that make this work

01 · DSA

Struggle 30 minutes first

Try every A2Z problem alone for 20–30 min: brute force first, then optimise. Only then watch Striver's video. Write the pattern in one line in your notes ("prefix sum + hashmap").

02 · AI

Watch 1×, code 2×

Follow the lecture once, then close it and rebuild the code from a blank file. If you can't, you don't know it yet. That's the whole trick.

03 · Revision

1 day, 1 week, 1 month

Re-solve each problem 1 day, 7 days and 30 days later. Use the 21:15 block and Sunday for this. Anki cards for formulas and definitions.

04 · Proof

Commit every day

Everything goes into your GitHub repo 'ai-journey': notes, notebooks, solutions. Recruiters read green squares and READMEs.

05 · Projects

Ship, don't polish

Every phase ends in a deployed project with a README: problem, approach, results table, demo link. Five of those beat twenty certificates.

06 · Pace

Behind? Cut, don't cram

If a week overruns, drop the hardest DSA items to Sunday and move on. Keep the AI track on schedule; consistency beats intensity. Protect sleep.
