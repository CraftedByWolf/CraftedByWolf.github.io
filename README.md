# surya CV's

Everything for Suriya K S's path from beginner to job-ready AI engineer (16 Nov 2026 → 13 Jun 2027).

| Folder | What it is |
|---|---|
| `index.html` | Portfolio / CV site (styled after aditya-00-9.github.io), built from LinkedIn |
| `roadmap/` | The 30-week study guide: today's plan, every week with checkboxes, routine, study rules |
| `wallpaper/` | Live desktop wallpaper for Lively Wallpaper: clock, current routine block, today's topics |
| `wallpaper/plan.js` | **The single source of truth.** Weeks, topics, resources and daily routine. Edit here; the guide and wallpaper both update |

## The plan in one picture

Every day runs three tracks:

- **DSA in Python** (07:00–09:30): Striver's A2Z sheet, Steps 1 → 18, then timed revision
- **AI track** (15:00–18:00): Foundations → ML → Deep Learning → NLP → GenAI → RAG → MCP → Capstone
- **SQL on the side** (20:30–21:15): basics → joins → window functions → LeetCode SQL 50 → daily practice

| Weeks | Phase | Ends with |
|---|---|---|
| 1–3 | Foundations (Python, tools, NumPy/pandas, maths) | CLI app + EDA notebook |
| 4–8 | Machine Learning | Project 1: deployed ML app |
| 9–13 | Deep Learning (micrograd, PyTorch, CNNs, RNNs) | Project 2: model behind an API |
| 14–17 | NLP (embeddings, transformers, Hugging Face) | Project 3: deployed NLP app |
| 18–20 | Generative AI (APIs, prompting, fine-tuning, agents) | Agent app |
| 21–23 | RAG (vector DBs, reranking, evals) | Project 4: production-style RAG |
| 24–25 | MCP & multi-agent systems | Your own MCP server |
| 26–30 | Capstone, portfolio, interview prep, applications | Live capstone + applications |

## Changing the routine

Open `wallpaper/plan.js` and edit `ROUTINE` (times are 24h). Lively keeps its own copy, so then right-click `update-wallpaper.ps1` → Run with PowerShell.

## Daily habit

Commit something every day: notes, notebooks, solutions. Tick items in the roadmap page as you finish them.
